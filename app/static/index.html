CONFIGURATION

A mind of its own.

Shape how your agent thinks, creates, and behaves.

Personality & instructions

Image generation & editing

Inline photos appear directly in the conversation. Choose original files when preserving quality or transparency matters.

Conversation memory

Each request includes up to 10 previous messages from the last hour, in the same chat and topic. The agent can look further back and fetch referenced media when needed. History starts when Moose observes messages; media is downloaded only on demand.

Message text and file references are encrypted on this server. Revoking chat access deletes its stored history.

Consciousness

One-time analysis of retained text in allowed chats, using your saved personality and guidance. Uses the configured AI provider and saves the result automatically. Available only while consciousness is empty.

Natural replies

Occasionally let Moose send several short messages or create a relevant meme without being asked. The model decides whether it fits; serious conversations should stay focused.

Replies when named

With occasional participation enabled, a name in any human message or caption among the latest 10 messages within the last hour in this chat/topic qualifies even without three messages from two people. Uses the same minimum context, pause, daytime hours, cooldown, and daily limits. Rolls once per pause and may still choose silence. Explicit @tags follow the usual direct-reply behavior.

Daytime & participation limits

Unprompted messages are limited to allowed groups. Private chats and channels still need an explicit mention. Disable Telegram privacy mode or make Moose an admin so it can hear the conversation.

Both modes share these limits across all topics in a group. Attempts count even if the model stays silent or a request fails. Overnight windows are supported; start and end must differ.

Wake up a quiet chat

Join a conversation

Requires at least three human messages from two people in the last hour, with a human speaking last. Skips pauses older than an hour. Moose can choose to stay silent.
